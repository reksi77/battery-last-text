A program that writes one line of plain text — the phone battery's last text message to the charger it waited for all day. The joke is jealousy, not a dying complaint: stood up all day, the battery moved on to the power bank, so the twist lands in the final words — it got full without the charger ever showing up.

## Run it

```sh
node main.ts
```

It writes the message to `/output/entry.txt` (178 characters, UTF-8, no trailing newline) and verifies the length and the written content before exiting.
